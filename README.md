# Секундомер

Проект создан на основе [Simple Clock](https://github.com/SimpleMobileTools/Simple-Clock/).
Основные функции — секундомер, отсечки с подписями и история сохранённых замеров.

Управление при открытом приложении:

- **Громкость +**: начать или продолжить замер; во время работы — сделать отсечку.
- **Громкость −**: поставить замер на паузу.
- **Кнопка запуска на экране**: начать или продолжить замер; во время работы — сделать отсечку.
- **Сохранить**: записать завершённые отсечки в историю с указанным названием группы или её порядковым номером.

В списке показываются только зафиксированные отсечки: время каждой строки останавливается сразу после нажатия.
Сброс секундомера и удаление отсечек требуют подтверждения.

Длительность считается по системным монотонным часам, включая сон устройства.
Текущий замер, подписи и отсечки сохраняются и восстанавливаются после завершения процесса приложения.
После перезагрузки телефона восстанавливается последнее сохранённое время на паузе.
Управление клавишами при заблокированном экране или поверх других приложений не реализовано.

Для сборки нужны JDK 17, Android SDK 34 и доступ к зависимостям из Google Maven, Maven Central и JitPack.
Проверка логики секундомера, восстановления состояния, миграций базы и сборка отладочного APK:

```sh
bash ./gradlew testCoreDebugUnitTest assembleCoreDebug
```

Пробная версия 2.0 для отдельной установки рядом с текущим приложением:

```sh
bash ./gradlew assemblePreviewRelease
```

Это сборка типа release с тестовой подписью и отдельным идентификатором
`com.simplemobiletools.clock.preview`. Она не заменяет установленную версию и её данные.
Для выпуска обновления основного приложения нужен его исходный ключ подписи.

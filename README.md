# Секундомер

Проект был прямо скопирован из [Simple-Clock]([SimpleMobileTools/Simple-Clock: Combination of a beautiful clock with widget, alarm, stopwatch & timer, no ads](https://github.com/SimpleMobileTools/Simple-Clock/tree/master?tab=GPL-3.0-1-ov-file)), удалены практически все функции, кроме секундомера.
Функционал:
- Старт, фикстирование отсечки, удалить все отсейки на клавишу Увеличить громкость
- Пауза на Уменьшить громкость
- Возможность сохранения отсечек с тегом. Если тега нет, то будет присвоен порядковый номер.

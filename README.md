# Секундомер

Проект был прямо скопирован из [Simple-Clock](https://github.com/SimpleMobileTools/Simple-Clock/), удалены практически все функции, кроме секундомера.
Функционал:
- Старт, фикстирование отсечки, удалить все отсейки на клавишу Увеличить громкость
- Пауза на Уменьшить громкость
- Возможность сохранения отсечек с тегом. Если тега нет, то будет присвоен порядковый номер.
